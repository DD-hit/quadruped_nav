# 初始定位覆盖测试

结论：不能保证任意初值定位成功。当前是有初值的局部 ICP（迭代最近点）配准；较大误差下存在误定位被接受。

## 测试范围

- 使用现有完整房间地图，19 个位置、8 个朝向（每隔 45°），每次单独初始化，7 组初值，共 1,064 次静态核心配准。
- 准确初值组也只输入平面位姿，roll/pitch（横滚/俯仰）和 z 设为 0，并未直接提供完整三维真值。
- 独立完整链路抽样：Isaac 物理传感器 → FAST-LIO → 单次 `/initialpose` → 当前定位器。初值带预设误差；仿真真值仅离线评分，不反馈给算法。
- 保留生产配准门限、地图、算法；完整链路采用上一版成功演示的定位配置（静止速度阈值 0.12 m/s，跟踪从精配准层开始），不是全部默认参数。
- 评分标准：位置误差 ≤ 0.18 m，整体旋转误差 ≤ 5°。这是本次工程测试阈值，不是雷达或真机精度承诺。超限不全是严重误定位，另统计位置 > 0.5 m 或旋转 > 30° 的明显错误。

## 原因与边界

- 雷达自身旋转朝向任意，与初值朝向错误是两件事。实际朝向为 180°、同时给出约 180° 初值，可以正常进行局部配准。
- ICP 从给定初值附近找局部最优，不执行整张地图的全位置/全角度搜索。长直墙、地面、天花板和重复几何可能让错误位置仍有很低的残差。
- 当前 fitness（匹配比例）、RMSE（均方根误差）与修正跳变门限不能验证解的唯一性。跳变门限限制相对于初值的修正量；若错误初值附近存在局部最优，修正很小也可能被接受。
- 静态覆盖使用 6,000 射线/帧、10 Hz、0.1–20 m 的现有几何代理。未模拟厂家扫描花纹、真实噪声、机器人自身遮挡，不代表真实 Mid-360S 验收。
- 有限房间、离散摆位与单次扫描不能证明“任意点位都成功”；未覆盖动态障碍、室外、楼梯、严重遮挡、雷达或 IMU 实际误差。
- 地图由 LIO 建立，相对物理几何可能存在自身误差；评分没有拟合额外对齐变换来美化结果。

## 建议下一步

先处理错误初值被接受的问题，再做 Web 上位机。若仍采用当前局部 ICP，应明确要求合理初值并增加初始化可信度验证；若希望位置/朝向未知也能恢复，需要独立的全局候选搜索与歧义判定。具体算法改动另行设计，本轮没有修改生产算法。
