## 实际修改

1. 地图保存时使用最后一段稳定的估计重力，重新确定地图竖直方向。所有几何统一刚性旋转，原点和物体间距离保留，定位 PCD 与导航 PCD 保持同一坐标系。原代码在建图早期冻结的参考方向被一直沿用到导出。
2. 新导入流程默认每体素最少 3 点、最小连通簇 4 个体素；参数仍可配置。当前稀疏边缘、细小物体的真机保留效果尚未验证，不作为通用硬件标定值。
3. 支撑判定增加现有机器人半径范围内的面积支撑检查，当前阈值 0.8，使用配置中的 2 层向下支撑搜索。中心下方一个占据格不再足以让狭小箱子、柱子顶部可通行。该比例是可配置近似，不是真实足端支撑多边形。
4. 支撑比例随地图元信息保存；导出文件记录最终坐标变换和重力窗口。
