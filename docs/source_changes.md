原始参考代码位于 third_party/reference，不参与构建。自有 ROS 包、节点和入口统一命名，保留上游许可证、声明及 migration_sources.json 文件映射。

## 接口适配

- 全局节点补充标准 GetPlan 服务，复用原 A* 和地图图层。
- SCAN 使用参考路径模式，保留原生重规划、碰撞检查和闭环速度算法。
- 任务开始、取消和切换在原生状态机/控制器中明确重置；过期路径和轨迹不能重新启动旧任务。
- 给原控制器补充目标最终朝向和完成反馈；完成时同时满足规划终点与用户目标的位置容差，避免栅格吸附误差叠加。
- 标准 Odometry 的机身速度转换到规划坐标后再供 SCAN 使用。
- 地面路径转机身轨迹保留相对地形高度，避免重复添加 body_height。
- 定位里程计过期时，控制器停车，任务接口返回失败。

## 上游缺陷修正

- 最近可行栅格原先返回搜索立方体中第一个可行角点；改为按距离搜索，优先保留目标 XY，避免纯高度吸附造成多余横向偏移。原占据、支撑及可通行检查保留。
- polynomial_traj.h 的 getMeanVel 缺少返回值，补齐返回及零时长处理。
- Python 地图管理节点补充可控退出，避免关闭时挂起。

模型、外参、外部定位、传感器和平台适配资料保留；旧导航实验脚本、历史阶段文档、工具产物已归档。归档清单位于 `/data0/rl/quadruped_nav/runs/navigation_core_before_cleanup_20261111_01/removed_paths.json`。


## 2026-11-12 故障修正

- 优化器和精修器的碰撞采样改为与 SCAN 安全检查相同的 `0.01 s`，修正粗采样漏检后立即急停的问题。
- B-spline 可执行性按速度 / 加速度向量范数判定，显式收紧原生容差，与控制器合成速度口径一致。
- 精修后重新检查导数控制点界，必要时整体缩放 knot 时间。路径形状不变，参考速度和加速度按比例降低；保持最终动态检查，不放宽阈值。
- 修正可执行性比值计算中的负哨兵：无加速度越界时不再由 `sqrt(abs(-1 / max_acc))` 产生无关的时间缩放。
- 重规划保留 jie 全局路线的剩余点；接收新任务时清空旧路线和进度。

原失败传感器回放、碰撞检查对照和修复前源码备份见 [失败诊断](failure_diagnosis_20261111.md)。原生重定时测试使用记录的第 18、19 条轨迹核对限速和几何不变性；完整接口、绕障测试和新版 Isaac 单点 / 多点闭环已通过。

## 2026-11-17 导航集成与动态地图修正

保留 jie 全局规划与 SCAN 局部规划，修正剩余路线种子、局部 A* 端点、完整轨迹碰撞检查、精确样条边界与静止时安全重定时、失败重试让出传感器处理时间、任务保持及零速度急停。实时观测保存 3 s，过期前用原始静态 OctoMap 保护已知静态占据；读取同一静态禁行层。实验性的额外机身外推急停规则已撤销。参数、成功和失败范围见 [本轮报告](navigation_dynamic_fix_20261117.md)。
